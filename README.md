# Lograr Studious LLC Website

Marketing site for Lograr Studious LLC, a software studio.

Plain HTML, CSS and JavaScript. No build step.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Files

- `index.html` - page content and sections
- `styles.css` - all styling (colors are set as variables at the top)
- `script.js` - menu, scroll effects, services carousel, contact form
- `assets/favicon.svg` - site icon

## Things to update

- **Contact email:** change `CONTACT_EMAIL` in `script.js`.
- **Projects:** edit the five `<article class="project">` cards in `index.html`.
- **Services:** edit the `services` list in `script.js`.
- **Colors:** change `--accent`, `--plum` and `--cream` in `styles.css`.

## Deploy

Any static host works (Vercel, Netlify, GitHub Pages).
